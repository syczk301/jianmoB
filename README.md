# 氢燃料电池低温冷启动建模与控制策略研究

B 题问题一至问题四的最终 Python 代码。项目围绕燃料电池低温启动中的传热、水冰相变、电化学响应及辅助加热控制展开，依次完成单电池参数标定、五片电堆加载策略优化、辅助加热方案设计和不同预冷工况下的控制优化。

四个脚本均已整合各自需要的模型、求解、绘图和导出函数。仓库包含 `Q1.py`—`Q4.py`、两份题目附件、配套上游参数表和 `requirements.txt`。克隆仓库并安装依赖后，即可执行各问；结果表格、运行日志和图像在运行时生成。

## 四问内容与方法

| 入口 | 研究内容 | 求解方法 |
| --- | --- | --- |
| [Q1.py](Q1.py) | 单电池水—冰—热—电耦合建模与参数辨识 | 五层一维有限体积离散；差分进化—信赖域反射精修；使用 −20 ℃工况校准，使用 −25 ℃工况验证 |
| [Q2.py](Q2.py) | 五片电堆恒流、线性升载和阶梯升载比较，及最低启动初温搜索 | Sobol 采样、可行性优先模式搜索和局部精修；完整网格复算与临界初温细化 |
| [Q3.py](Q3.py) | 纯预热与恒定功率协同启动的功率分配和加热时长优化 | 镜像对称功率参数化、自适应网格直接搜索与序列最小二乘精修；细步长核验 |
| [Q4.py](Q4.py) | 三种初始温度场下的恒功率与动态功率控制比较，及预冷时间扫描 | 全厚度预冷模型；能耗、峰值功率与高功率暴露的多目标优化；差分进化、单纯形精修和峰值分档补搜 |

Q2—Q4 读取 Q1 导出的标定参数；Q3 使用 Q2 的线性升载参数；Q4 的预冷时间扫描使用 Q3 的协同加热方案作为搜索起点。

## 快速开始

### 1. 获取代码与安装依赖

```bash
git clone https://github.com/syczk301/jianmoB.git
cd jianmoB
```

已完成校验的环境为 **Python 3.12.12**，依赖版本如下：

| 依赖 | 版本 |
| --- | --- |
| NumPy | 2.1.2 |
| pandas | 2.3.3 |
| SciPy | 1.15.3 |
| openpyxl | 3.1.5 |
| Matplotlib | 3.10.7 |

在 Python 3.12 环境中安装：


中文图表使用系统字体，绘图环境可安装 Microsoft YaHei 或 Noto Sans SC。图像采用 Matplotlib 的 Agg 后端，支持在终端环境生成。

## 第四问：论文方案与重新优化

### 默认复算

```bash
python Q4.py
```

三种工况分别为均匀 −30 ℃初态，以及从 25 ℃开始、在 −30 ℃环境中预冷 20 分钟和 40 分钟形成的温度场。默认动态控制参数及各自的设计功率上限保存在 `Q4.py` 的 `_FINAL_SELECTED` 中，恒功率对照参数保存在 `_PAPER_BASELINES` 中。

论文最终参数的复算结果如下：

| 工况 | 恒功率对照能耗 / J | 最终方案能耗 / J | 节能率 |
| --- | ---: | ---: | ---: |
| 均匀 −30 ℃ | 5190.18 | 4956.09 | 4.51% |
| 预冷 20 分钟 | 646.35 | 107.30 | 83.40% |
| 预冷 40 分钟 | 3206.40 | 2200.13 | 31.38% |

恒功率对照采用 0.05 s 时间步，最终动态方案采用 0.0125 s 时间步。上述数值对应原附件、配套标定参数及内置控制参数；更新输入或重新求解后，以本次生成的结果为准。

预冷 40 分钟工况选中的控制方案，其四项反馈增益均为零，对应动态控制族中的延迟恒功率方案。

三工况方案核验启动成功、最大片间温差 ≤ 5 ℃、实际加热功率密度 ≤ 1 W/cm²、累计电荷 ≤ 20 C/cm²、最低单片电压 ≥ 0.30 V，以及最大局部冰体积分数 < 0.99。设计功率上限随控制参数一同参与复算。

### 重新执行完整优化

```bash
python Q4.py --search
```

该选项依次执行统计一致性检查、多目标搜索、峰值分档补搜、候选合并和三步长核验，再用本次选出的参数生成主结果。搜索过程使用 0.05、0.025、0.0125 s 三种细步长核验候选方案，搜索记录与复核文件保存到 `Q4/`。

多目标评价综合归一化能耗、实际峰值功率和平滑高功率暴露，考察权重 `0.05`、`0.2`、`0.8`，主结果采用均衡权重 `0.2`。`--search` 包含多轮优化，其计算量高于默认复算。

重新搜索选出的参数用于本次运行，完整参数保存在搜索 JSON 中。脚本内置参数保持原值；后续直接执行 `python Q4.py` 时仍以内置论文方案为准。
